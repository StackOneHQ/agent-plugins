# stackone-connectors

Discover StackOne's connectors and 30,000+ actions across HR, Sales, Marketing, IT, finance and collaboration tools (Workday, SAP, Oracle, Salesforce, Google, Microsoft and hundreds more).

## Install

```bash
/plugin marketplace add stackonehq/agent-plugins
/plugin install stackone-connectors@stackone-agent-plugins
```

## Use

- "Which providers does StackOne support?"
- "What can I do with BambooHR?"
- "Recommend an integration for HR"
- "What actions are available?"
