# stackone-connection

Connect and set up accounts: link, reconnect a broken connector, choose a connector profile, and diagnose a new link.

## Install

```bash
/plugin marketplace add stackonehq/agent-plugins
/plugin install stackone-connection@stackone-agent-plugins
```

## Use

- "Connect my account"
- "Reconnect my expired connector"
- "Which profile should I link through"
- "Check that my new account works"
