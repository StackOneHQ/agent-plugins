# stackone-dashboard

Understand the StackOne dashboard at app.stackone.com: connector profiles, accounts, roles, policies, logs, webhooks, data sync.

## Install

```bash
/plugin marketplace add stackonehq/agent-plugins
/plugin install stackone-dashboard@stackone-agent-plugins
```

## Use

- "What is a connector profile"
- "Why is my linked account in error"
- "How do roles and groups work"
- "Enforce vs monitor policy"
